## About

I build hands-on projects that connect user-facing applications with data pipelines, machine learning, and backend services. My repositories include a study co-pilot, a credential manager, a real-estate insights prototype, a streaming crypto dashboard, and an image-based malware classification study.

## Featured projects

<details>
<summary><strong>Crocademy / StudyPilot</strong> - voice-first study planning with a persistent MCP-enabled co-pilot</summary>

Create study plans, organize and reschedule tasks, run focus sessions, and track topic confidence. Croc can use browser speech features and server-side Bedrock replies, with a keyword fallback that works without AWS credentials.

| Stack | Scale | Performance | Security | Impact | Repository |
|---|---|---|---|---|---|
| React, Vite, Express, MCP, optional Bedrock | App prototype | No benchmark published | AWS credentials stay server-side | Persistent study tasks, plans, sessions, and topic progress | [Crocademy](https://github.com/furkmez20/Crocademy) |

Demo: no public deployment listed.

</details>

<details>
<summary><strong>VaultGuardian</strong> - Flask credential manager with MFA and encrypted credential storage</summary>

Manage saved credentials behind account login and TOTP or email one-time codes. The app uses SQLAlchemy with SQLite by default.

| Stack | Scale | Performance | Security | Impact | Repository |
|---|---|---|---|---|---|
| Python, Flask, SQLAlchemy, SQLite, Fernet, WTForms | Local web app | No benchmark published | Password hashing, MFA, and encrypted credential data; learning project, not production validated | Save and manage credential records | [VaultGuardian](https://github.com/furkmez20/VaultGuardian) |


</details>

<details>
<summary><strong>HackUTD2025 / EstateWise AI</strong> - real-estate portfolio insights prototype</summary>

Combines a Next.js interface with a FastAPI service for property, lease, and operational data, Auth0 token checks, and Gemini-backed summaries. The repository also includes sample portfolio data.

| Stack | Scale | Performance | Security | Impact | Repository |
|---|---|---|---|---|---|
| Next.js, React, FastAPI, SQLAlchemy, PostgreSQL, Gemini, Auth0 | Prototype with sample data | No benchmark published | Auth0 JWT checks on protected API routes | Explore property, lease, and operating data | [HackUTD2025](https://github.com/furkmez20/HackUTD2025) |

Demo: no public deployment listed.

</details>

<details>
<summary><strong>CryptoFlow</strong> - real-time cryptocurrency streaming dashboard</summary>

Streams market prices through Kafka and Spark, stores results in MongoDB Atlas, and displays live charts with Streamlit.

| Stack | Scale | Performance | Security | Impact | Repository |
|---|---|---|---|---|---|
| Python, Kafka, Spark, MongoDB Atlas, Streamlit | Tracks five cryptocurrencies | 30-second polling and dashboard refresh | Connection settings need review before deployment | Live market and price-history dashboard | [CrptoFlow](https://github.com/furkmez20/CrptoFlow) |

Demo: [Live dashboard](https://cryptoflow.streamlit.app/).

</details>

<details>
<summary><strong>Multi-Model CNN Study for Malware Detection</strong> - image-based malware classification experiment</summary>

Compares a whole-image CNN, an improved CNN, and a multi-region CropCNN on grayscale executable images. CropCNN reports 93.75% test accuracy in the documented experiment; this does not establish real-world malware detection performance.

| Stack | Scale | Performance | Security | Impact | Repository |
|---|---|---|---|---|---|
| Python, TensorFlow/Keras, Google Colab | Limited experimental dataset | 93.75% reported test accuracy for CropCNN | Educational study, not a production detector | Compares three image-classification architectures | [Study repository](https://github.com/furkmez20/Multi-Model-CNN-Study-for-Malware-Detection) |

</details>
